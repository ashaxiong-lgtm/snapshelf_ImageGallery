****Snapshelf: Image Gallery****

A responsive image gallery built with plain HTML, CSS and JavaScript (no frameworks). Browse photos in a masonry grid, filter by category, open any photo in a lightbox and edit it with live filters. Made as Task 1 of my internship.

****LiVE DEMO :****
https://snapshelfimagegallery.vercel.app/

**Features**

**Core requirements**
Image gallery layout with HTML and CSS (masonry grid, photos in "slide mount" cards),
JavaScript lightbox with next / previous buttons,
Hover effects and smooth transitions (card lift, image zoom, fade-in loading),
Responsive design for phone, tablet and laptop.

**Bonus features**
Category filters (All, Nature, City, Portrait, Abstract) ,
Live search by photo title or category ,
Photo editor in the lightbox: 
Presets: Original, Vibrant, Dreamy, Vintage, B&W, Faded ,
Sliders: blur, brightness, contrast, vibrance, black & white, warmth, opacity,
Reset button and download of the edited photo as PNG,
Edits are saved in the browser (localStorage),
Three themes: Light, Dark and Blue mode .

**Tech used**
1. HTML5,
2. CSS3 (Grid / columns, Flexbox, CSS variables, media queries, color-mix),
3. Vanilla JavaScript (DOM, events, Canvas API, localStorage).

**Project structure**
index.html :   page structure ,
style.css :   layout, themes, animations, responsive rules ,
script.js  :  photo data, filters, lightbox, editor, themes .

**Use your own photos**
Open script.js and edit the photos array at the top. Put your images in an images/ folder and set each src, for example images/forest.jpg, plus its title and category.
